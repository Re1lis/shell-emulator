# Эмулятор оболочки

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.
Практическая работа по дисциплине «Конфигурационное управление»,
вариант 28. Язык: Python 3, графика на tkinter.

## Общее описание

Приложение открывает окно с областью вывода и строкой ввода.
Заголовок окна формируется из данных реальной ОС:
`Эмулятор - [username@hostname]`.

Текущий статус: этап 2 (конфигурация).

## Функции и настройки

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | Заглушка: выводит имя команды и аргументы |
| `cd [аргументы]` | Заглушка: выводит имя команды и аргументы |
| `exit` | Закрывает эмулятор |

Аргументы можно заключать в одинарные или двойные кавычки,
тогда текст в кавычках считается одним аргументом.

Ошибки (неизвестная команда, незакрытая кавычка) выводятся в окно,
эмулятор продолжает работать.

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs ПУТЬ` | Путь к физическому расположению VFS |
| `--script ПУТЬ` | Путь к стартовому скрипту |

При запуске в окно выводятся все заданные параметры
(строки с пометкой `[отладка]`).

### Стартовый скрипт

Текстовый файл, в каждой строке одна команда эмулятора. Команды
выполняются по очереди, в окне видны и ввод, и вывод. Строки с
ошибками (неизвестная команда, незакрытая кавычка) выводят сообщение
об ошибке, и выполнение продолжается.

## Запуск

Нужен Python 3 с tkinter.

```
run.bat
```

или

```
python src/main.py
```

С параметрами:

```
python src/main.py --vfs vfs/test.zip --script scripts/demo.txt
```

Скрипты для проверки параметров (Windows):

```
scripts\test_params.bat
scripts\test_errors.bat
```

## Структура

```
src/main.py       точка входа
src/gui.py        окно эмулятора
src/commands.py   разбор и выполнение команд
src/sysinfo.py    данные о реальной ОС
scripts/          стартовые скрипты и bat-файлы для проверки
tests/            тесты
```

## Примеры использования

```
user@host:~$ ls -l "my dir"
ls ['-l', 'my dir']
user@host:~$ cd /tmp
cd ['/tmp']
user@host:~$ foo
foo: команда не найдена
user@host:~$ ls "abc
Ошибка: незакрытая кавычка
user@host:~$ exit
```

Запуск со стартовым скриптом:

```
python src/main.py --script scripts/demo.txt
```

## Сборка и тесты

Сборка не нужна, проект запускается как есть.

```
python -m pip install pytest

```
